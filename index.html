API key และโมเดล

key เก็บไว้ในเครื่องนี้เท่านั้น (ในเบราว์เซอร์) และส่งตรงไปยังผู้ให้บริการแต่ละราย ไม่ผ่านเซิร์ฟเวอร์อื่น

คำสั่งพื้นฐานที่ใช้กับ AI ทุกตัว

การใช้งาน token (สะสมในเครื่องนี้)

ข้อมูล

3 โหมดการทำงาน

  • ตัวเดียว — ถาม AI ตัวที่เลือก เร็วและถูกที่สุด
  • ถามทุกตัว — ส่งคำถามเดียวกันให้ทุกตัวที่เลือกพร้อมกัน แล้วให้ “ผู้สรุป” รวมจุดดีของแต่ละคำตอบเป็นคำตอบเดียว เหมาะกับคำถามที่ต้องการความแม่นยำ
  • ทีมงาน — ตัวที่ 1 ร่าง → ตัวที่ 2 ตรวจหาข้อผิดพลาด → ตัวที่ 3 เรียบเรียงฉบับสุดท้าย เหมาะกับงานเขียน แผนงาน หรือโค้ด

ทุกโหมดใช้ประวัติแชทเดียวกัน AI ทุกตัวจึงรู้ว่าคุยอะไรกันไปแล้ว กด “ดูขั้นตอน” ใต้คำตอบเพื่อดูว่าแต่ละตัวตอบอะไร

สมัคร API key

ค่าสมาชิกแอป (ChatGPT Plus, Claude Pro, Gemini Advanced) ไม่รวม API ต้องสมัครแยกและเติมเงินตามการใช้งาน

  • ChatGPT: platform.openai.com/api-keys
  • Claude: console.anthropic.com
  • Gemini: aistudio.google.com/apikey

แนะนำให้ตั้งวงเงินสูงสุดต่อเดือนในหน้าบิลของแต่ละค่าย เพื่อกันค่าใช้จ่ายบานปลาย

ติดตั้งบน iPhone / iPad

  1. เปิดหน้านี้ใน Safari
  2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
  3. เลือก “เพิ่มไปยังหน้าจอโฮม”

บน iPad ที่มีคีย์บอร์ด กด ⌘ + Enter เพื่อส่ง
